# oo-rust

This repository demonstrates, which oo features Rust possesses, making it (in my opinion) an (almost) complete object-
oriented language.


It demonstrates the following OO-releated features
- Encapsulation
  - Bundling data and methods together
  - Protection
- Implementation
  - Implementing methods of an interface
  - Polymorphism / Dynamic Binding

  The only lacking thing is inheritannce, which the branch `real_inheritance` tries to introduce.
